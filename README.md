# shopcart

A small shopping-cart library used as a QA practice project for the AI Employee team.

- `src/shopcart/cart.py`: the cart (items, quantities, subtotal, GST total)
- `src/shopcart/discounts.py`: coupon codes

Requirements live in the team's trackers (Jira project SCRUM and Linear team WLL), not in this repo.

Run the tests: `pip install -e . pytest && pytest`
